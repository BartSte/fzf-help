# Contributing to fzf-help

Thank you for contributing to `fzf-help`.

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork with the `develop` branch:

   ```sh
   git clone --branch develop https://github.com/<your-user-name>/fzf-help.git
   ```

3. Create a new branch:

   ```sh
   git switch -c <branch-name>
   ```

4. Make your changes.
5. Commit your changes.
6. Push your changes to your fork.
7. Create a pull request on GitHub.

## Reporting Bugs

If you encounter any bugs or issues, please report them on the issue tracker
at:

[Issues](https://github.com/BartSte/fzf-help/issues)
